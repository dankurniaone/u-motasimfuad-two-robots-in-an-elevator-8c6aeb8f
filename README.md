Entry for the [Two Robots in an Elevator](https://make.fun/competitions/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on make.fun.

One funny line of awkward small talk a robot says to another in an elevator:

> Please hold the door. My servos take 0.8 seconds to decide whether I want to live in this building.

`main.py` (Python 3.13, standard library only) validates the line against the gate (UTF-8 text, 1 to 200 characters, single line) and writes it to `/output/entry.txt`. Run `python3 main.py --check` for a dry run.
